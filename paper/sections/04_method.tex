\subsection{The reference channel is itself a quantiser}
\label{sec:refquant}
% A genuine methods contribution, and the most transferable thing in the
% paper: anyone using a higher-resolution channel as ground truth for a
% lower-resolution one has this problem and will not have corrected for it.
%
% The 20-bit field truncates on a Delta/8 lattice, so phi read from it is low
% by 1/16 Delta and its variance carries Delta'^2/12. Sheppard's own 1898
% correction, applied to the instrument's reference channel.
%
% The cascade is transparent: because Delta' divides Delta exactly,
%     floor( floor(x/Delta') Delta' / Delta ) = floor(x/Delta)
% identically, so Q is unchanged and only Var[x] needs correcting.
\expl{Found by fitting a free offset to a residual, not predicted in advance.
The out-of-sample evidence is what makes it defensible: derived from the
\SI{50}{\hertz} phase sweep, applied unchanged to the independent ODR axis,
\refImprovement{} residual improvement on data it was not derived from. Say
this plainly rather than presenting it as a prediction.}
